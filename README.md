Hoe wil ik in de juiste bestandsmap komen om het te testen

dit word in de terminal geddan:

git clone https://github.com/StijnR7/GeoProfs.git

git checkout git checkout 528439b
(dan kom je in de juiste branch terecht)

Hierin moet je het bestand geoprofs zoeken en eruit halen in een ander bestand zetten zodat je de gehele applicatie ziet zoals het moet.
Als je dit niet doet blijft het geoprofs bestand van Stijn erin staan waardoor die C# ziet en nog andere laravel code. Dit kan niet weggehaald of gefixt worden vanwege dat Stijn in een andere IDE werkt dan wij met een andere taal.
