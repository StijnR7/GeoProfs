Geoprofs:

Dit is de manager app van ons geoprofs project. Dit is waar de manager zijn dingen doet. 
Voorbeelden van functies in deze app zijn:

-Inloggen
-Verlofaanvragen inzien en accepteren of afwijzen.
-Automatische updates via de email wanneer een aanvraag geaccepteerd of afgewezen is.
-Automatische tips of de manager de aanvraag kan accepteren gebaseerd op de settings
-het maken en aanpassen van user accoutns

Als je de github cloned en in visual studio opent, kan je de app starten. Ik zal hem wanneer hij klaar is ook naar .exe omzetten, zodat je die kan opstarten.

Hij is verbonden met een MariaDB database die online gehosted is via filess.io.


Ik heb besloten hier c# voor te gebruiken omdat het mijn beste taal is. De keuze in database was door de aanbeveling van een docent.
voor de code zelf waren de beslissingen door mij gemaakt. Mijn doel was om het simpel te houden, efficient en geen dubbele coding (of minimaal).
